Privacy Policy

Privacy information for Matrix HTTP Server, a local network file sharing server for Android.

Last updated · September 13, 2026
Matrix HTTP Server lets you share files directly from your Android device through a local HTTP server. Your files stay under your control and are not uploaded to a developer-operated cloud service.
Information CollectionFiles & Storage Network AccessSecurity Third PartiesContact

1. Information We Collect

Matrix HTTP Server does not collect, store, sell, or share personal information with the developer or third parties.

The app does not require an account and does not intentionally collect your name, email address, phone number, or location.

2. Files & Storage

The app can access files or folders that you explicitly select for sharing. Selected files remain on your device.

Your files are not uploaded to a developer-operated cloud server. They are made available through the local HTTP server only while you choose to run it.

3. Network Access

Matrix HTTP Server uses your device's network connection to provide an HTTP server for local file sharing.

Devices that can reach your server may be able to access the files you selected for sharing. Only run the server on networks and with devices you trust.

4. Data Security

The app does not intentionally transmit your shared files to an external server operated by the developer.

Because the app provides an HTTP server, you are responsible for using it on a trusted network and stopping the server when you no longer want files to be accessible.

5. Third Party Services

Matrix HTTP Server does not intentionally integrate advertising, analytics, tracking, or other third-party data collection services.

6. Children's Privacy

The app does not knowingly collect personal information from children or adults. No account or personal information is required to use the app.

7. Changes to This Policy

This Privacy Policy may be updated if the app's functionality or privacy practices change. The updated version will be published on this page with a revised date.
